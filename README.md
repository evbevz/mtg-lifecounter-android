# MTG LifeCounter — Android

Android-порт приложения MTG LifeCounter, написанный на Kotlin с использованием Jetpack Compose.

## Возможности

- **2 игрока** — переключение между игроками нажатием на панель сверху
- **Сетка жизней 10×4** — нажмите на число, чтобы установить уровень жизни (по умолчанию 20)
- **Прокрутка страниц** — свайп вверх/вниз по сетке меняет диапазон чисел на ±20
- **Счётчик отравлений** — от 0 до 20 для каждого игрока
- **Кубик (D6)** — анимированный бросок шестигранного кубика
- **Экран ожидания** — через 60 секунд бездействия показывает текущий уровень жизни на затемнённом экране
- **Экран не гаснет** во время игры
- **Сброс игры** — возвращает все значения к начальным

## Сборка

### Требования

- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17+
- Android SDK 34

### Шаги

1. Откройте папку `AndroidPort` в Android Studio как проект
2. Дождитесь синхронизации Gradle
3. Подключите устройство или запустите эмулятор (API 26+)
4. Нажмите **Run** (▶)

## Архитектура

- **Kotlin** + **Jetpack Compose** (Material 3)
- **MVVM**: `GameViewModel` хранит состояние игры
- **Однооконное приложение**: `MainActivity` → `GameScreen`
- Тёмная тема в стиле MTG (пергаментная карта, золотые акценты)

## Структура проекта

```
app/src/main/java/com/mtg/lifecounter/
├── MainActivity.kt          — точка входа
├── GameViewModel.kt          — модель данных и логика
└── ui/
    ├── theme/Theme.kt        — цвета, типографика, тема
    ├── GameScreen.kt         — главный экран
    ├── LifeGrid.kt           — сетка выбора жизней
    └── Components.kt         — панель игроков, яд, кубик
```
