# MTG LifeCounter — Android

Android-порт приложения MTG LifeCounter на Kotlin (Jetpack Compose) с OpenGL ES 2 кубиком, перенесённым с iOS.

Оригинальный проект: https://github.com/evbevz/mtg-lifecounter

## Возможности

- **2 игрока** — переключение шариком внизу (синий / красный). Пузырь под слотом остаётся всегда
- **Переключение игрока** — шарики сжимаются и гаснут, поле переворачивается, затем шарики появляются на новых местах. Счётчик яда меняется только после анимации
- **Сетка жизней 4×5** — жизнь задаётся перетаскиванием шарика на клетку, не тапом по числу. По умолчанию 20
- **Прокрутка сетки** — свайп вниз добавляет строки сверху (большие значения), свайп вверх — снизу. Ниже 1 сетка не уходит, выше 200 не прокручивается. Шарик остаётся на поле и у края меняет жизнь
- **Счётчик яда** — от 0 до 20. Слайд вверх по счётчику +1, вниз −1; тап по верхней / нижней половине — то же
- **Кубик (D6)** — 3D OpenGL-кубик с физикой iOS: бросок, стены поля, отскок от шариков. Тап по подставке возвращает его на место
- **Экран ожидания** — через 60 секунд бездействия показывает текущую жизнь на затемнённом экране
- **Экран не гаснет** во время игры

## Сборка

### Требования

- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17+
- Android SDK 34

### Шаги

1. Откройте папку `AndroidPort` в Android Studio как проект
2. Дождитесь синхронизации Gradle
3. Подключите устройство или запустите эмулятор (API 26+)
4. Нажмите **Run** (▶)

Меш кубика (`app/src/main/assets/dice_mesh.bin`) собран из iOS `CUBE_OBJ.h` скриптом `tools/convert_dice_mesh.py`. Пересобирать его нужно только если изменилась модель.

## Архитектура

- **Kotlin** + **Jetpack Compose** (Material 3) — интерфейс
- **OpenGL ES 2** — кубик поверх Compose (`DiceView` + `DiceEngine` + `DiceRenderer`)
- **MVVM**: `GameViewModel` хранит жизнь, яд и активного игрока
- **Однооконное приложение**: `MainActivity` кладёт Compose-экран и прозрачный GL-слой в один `FrameLayout`

Раскладка привязана к пропорциям iOS (768×1024). Размер шариков — `MARBLE_DISPLAY_SCALE` в `GameScreen.kt` (и на поле, и на переключателе). Пузыри — отдельно, `BUBBLE_DISPLAY_SCALE`.

## Структура проекта

```
app/src/main/java/com/mtg/lifecounter/
├── MainActivity.kt           — точка входа, Compose + слой кубика
├── GameViewModel.kt          — жизнь, яд, активный игрок
├── dice/
│   ├── DiceEngine.kt         — физика броска (порт DiceView.m)
│   ├── DiceRenderer.kt       — Phong-шейдер и меш
│   └── DiceView.kt           — GLSurfaceView и жесты
└── ui/
    ├── theme/Theme.kt        — цвета, шрифт Garamond, тема
    ├── GameScreen.kt         — главный экран и анимация смены игрока
    ├── LifeGrid.kt           — сетка, прокрутка, перетаскивание шарика
    ├── DiceObstacles.kt      — шарики как препятствия для кубика
    └── Components.kt         — счётчик яда, подставка кубика
```
